# Templates README

This directory contains markdown templates used by the Spec Kit to generate
feature specifications, plans, and tasks. Templates should use explicit,
machine-friendly placeholders so tooling can reliably replace values during
generation and updates.

Placeholder conventions (recommended)

- Acronyms: use the token format `{{ACRONYM:Artifact}}` where `Artifact` is a
  friendly name (e.g. `User Story`, `Requirement`, `Feature`, `Scoring`). When
  rendering numbered artifacts use the pattern: `{{ACRONYM:Artifact}}-{{NUMBER}}`.
  Example: `{{ACRONYM:User Story}}-1` -> `USR-1` (after resolving tokens).
- Generic placeholders: prefer `[[PLACEHOLDER_NAME]]` or bracketed capitals for
  human-editable fields that are NOT consumed by tooling, e.g. `[FEATURE NAME]`,
  `[DATE]`, `[PROJECT NAME]`.
- CLI args: use `$ARGUMENTS` where appropriate in generated templates to show
  runtime substitution points for commands.

Common placeholders found in templates

- `spec-template.md`
  - `[FEATURE NAME]`, `[DATE]`, `$ARGUMENTS`, `[UST-001]` (story id style)
  - Constitution Check references `.specify/memory/mcp-tools.md`
- `tasks-template.md`
  - `[FEATURE NAME]`, `[###-feature-name]`, sample `T-CON-01`/task ids
- `plan-template.md`
  - placeholders for language/version, structure, and tech choices
- `agent-file-template.md`
  - `[PROJECT NAME]`, `[DATE]`, autogenerated sections markers

Guidance for template authors

- Use `{{ACRONYM:...}}` in places where an acronym token should be resolved by
  tooling (see `specs/001-configurable-acronyms-jira-integration` for examples).
- Keep human-facing placeholders (like `[DATE]`, `[FEATURE NAME]`) clearly
  distinct from machine tokens to avoid accidental replacement.
- Prefer single-line tokens for easy grep and replacement. Avoid multiline
  tokens that are harder to parse.
- Document any new token formats in this README so downstream tools can be
  updated accordingly.

Examples

Template line:

```
**Feature Branch**: `[###-feature-name]`  
```

After generation (example):

```
**Feature Branch**: `001-configurable-acronyms-jira-integration`
```
